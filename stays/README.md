# Stays

## Purpose
This folder manages all accommodation-related planning and bookings for the Japan 2026 trip, including hotels, ryokans, hostels, or alternative lodging options.

## Objective
- Research and book accommodations across different cities in Japan
- Track booking confirmations and check-in details
- Organize accommodation by location and date
- Store information about amenities, policies, and local area details
- Maintain budget tracking for lodging expenses

## Plan
1. **Research Phase**
   - Identify cities and regions to visit in Japan
   - Determine number of nights needed in each location
   - Research accommodation types:
     - Traditional ryokans (Japanese inns)
     - Modern hotels
     - Capsule hotels
     - Airbnb or vacation rentals
     - Hostels or guesthouses
   - Read reviews and compare locations

2. **Booking Phase**
   - Book accommodations in advance for each destination
   - Confirm locations near public transportation
   - Verify amenities (WiFi, breakfast, luggage storage, etc.)
   - Check cancellation policies
   - Save confirmation numbers and contact information

3. **Documentation Phase**
   - Store booking confirmations and receipts
   - Document check-in/check-out times
   - Note special instructions (key pickup, access codes, etc.)
   - Save addresses in both English and Japanese
   - Keep emergency contact numbers for each property

4. **Organization by Location**
   - Create subfolders or documents for each city
   - Include nearby attractions and transportation info
   - Note luggage forwarding services (takkyubin) if using between hotels
   - Track total accommodation costs against budget
